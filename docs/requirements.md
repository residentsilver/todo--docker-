# Todo管理アプリケーション 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
Todo管理アプリケーション（サブスクリプションリマインド機能付き）

### 1.2 目的
ユーザーがTodoタスクを管理し、サブスクリプションサービスの終了日をリマインドするためのWebアプリケーションを提供する。

### 1.3 対象ユーザー
- 個人ユーザー
- タスク管理を必要とするユーザー
- サブスクリプションサービスの管理を必要とするユーザー

### 1.4 技術スタック
- **バックエンド**: Laravel (PHP 8.x)
- **フロントエンド**: React (JavaScript)
- **データベース**: MySQL 8.0
- **認証**: Laravel Sanctum
- **外部連携**: LINE Messaging API
- **インフラ**: Docker Compose
- **UIフレームワーク**: Material-UI (MUI)

## 2. 機能要件

### 2.1 ユーザー認証機能

#### 2.1.1 ユーザー登録
- **機能**: 新規ユーザーアカウントの作成
- **入力項目**:
  - ユーザー名（必須）
  - メールアドレス（必須、一意性）
  - パスワード（必須、最小8文字）
- **バリデーション**:
  - メールアドレスの形式チェック
  - パスワードの強度チェック
  - 重複メールアドレスのチェック
- **出力**: 登録成功時、自動的にログイン状態になる

#### 2.1.2 ログイン
- **機能**: 既存ユーザーの認証
- **入力項目**:
  - メールアドレス
  - パスワード
- **認証方式**: Laravel Sanctum（トークンベース認証）
- **セッション管理**: トークンによる認証状態の維持

#### 2.1.3 ログアウト
- **機能**: 現在のセッションを終了
- **動作**: トークンの無効化

#### 2.1.4 プロフィール管理
- **機能**: ユーザー情報の表示・編集
- **編集可能項目**:
  - ユーザー名
  - メールアドレス
- **認証**: ログインユーザーのみアクセス可能

---

### 2.2 Todo管理機能

#### 2.2.1 Todo一覧表示
- **機能**: ユーザーが作成したTodoアイテムの一覧を表示
- **表示項目**:
  - Todoタイトル
  - Todo詳細（TodoDetail）の一覧
  - 完了状態
  - 作成日時
- **ソート**: 順序（order）カラムによる並び替え
- **フィルタリング**: ログインユーザーのTodoのみ表示

#### 2.2.2 Todo作成
- **機能**: 新しいTodoアイテムの作成
- **入力項目**:
  - タイトル（必須）
  - 説明（TodoDetailとして自動作成）
- **自動処理**:
  - ユーザーIDの自動設定
  - 順序（order）の自動設定（最大値+1）
  - 初期TodoDetailの作成（completed: false）

#### 2.2.3 Todo更新
- **機能**: 既存Todoアイテムの編集
- **編集可能項目**:
  - タイトル
- **権限**: 作成者のみ編集可能

#### 2.2.4 Todo削除
- **機能**: Todoアイテムの削除
- **削除方式**: ソフトデリート（論理削除）
- **動作**: 
  - Todo削除時、関連するTodoDetailも自動的にソフトデリート
  - 削除されたTodoは削除済みTodoページで確認可能

#### 2.2.5 Todo順序変更
- **機能**: Todoアイテムの表示順序を変更
- **実装**: ドラッグ&ドロップまたは手動入力
- **保存**: バッチ更新で順序を保存

#### 2.2.6 TodoDetail管理
- **機能**: Todoに紐づく詳細タスクの管理
- **操作**:
  - TodoDetailの追加
  - TodoDetailの編集（説明、完了状態）
  - TodoDetailの削除（ソフトデリート）
  - TodoDetailの順序変更
- **完了状態**: チェックボックスで切り替え可能

#### 2.2.7 削除済みTodo管理
- **機能**: 削除されたTodoアイテムの表示・復元
- **表示内容**:
  - 削除されたTodo一覧
  - 削除されたTodoDetailのみを持つTodo一覧
- **復元機能**:
  - Todo全体の復元（関連TodoDetailも復元）
  - TodoDetail単体の復元
- **表示順**: 削除日時の降順

---

### 2.3 検索機能

#### 2.3.1 リアルタイム検索
- **機能**: Todoアイテムのリアルタイム検索
- **検索対象**:
  - Todoタイトル
  - TodoDetailの説明
- **検索方法**: 部分一致検索
- **UI**: ヘッダーに検索バーを配置
- **検索結果表示**: 検索結果をドロップダウン形式で表示

#### 2.3.2 検索クリア
- **機能**: 検索クエリのクリア
- **操作**: クリアボタンまたはESCキー

---

### 2.4 サブスクリプション管理機能

#### 2.4.1 サブスクリプション一覧表示
- **機能**: 登録済みサブスクリプションの一覧表示
- **表示項目**:
  - サービス名
  - 説明
  - 契約開始日
  - 契約終了日
  - 金額
  - 契約タイプ（月額、年額、無料トライアル、一回払い、その他）
  - ステータス（アクティブ、期限切れ、解約済み、一時停止、更新待ち）
  - 通知有効/無効
  - 残り日数
- **フィルタリング**:
  - ステータスによるフィルタ
  - 契約タイプによるフィルタ
- **ソート**:
  - 終了日順（デフォルト）
  - その他の項目によるソート
- **ページネーション**: 15件/ページ（デフォルト）

#### 2.4.2 サブスクリプション作成
- **機能**: 新しいサブスクリプションの登録
- **入力項目**:
  - サービス名（必須、最大255文字）
  - 説明（任意）
  - 契約開始日（必須、日付形式）
  - 契約終了日（必須、開始日より後）
  - 金額（必須、0以上）
  - 契約タイプ（必須、選択式）
  - URL（任意、URL形式）
  - リマインド日数（任意、配列形式、例：[30, 7, 1]）
  - リマインド時間（任意、HH:mm形式）
  - タイムゾーン（任意、デフォルト: Asia/Tokyo）
  - カスタムメッセージ（任意）
  - 通知有効/無効（デフォルト: 有効）
- **自動処理**:
  - ユーザーIDの自動設定
  - デフォルト設定の適用（ユーザー設定から）
  - リマインド履歴の自動作成

#### 2.4.3 サブスクリプション更新
- **機能**: 既存サブスクリプションの編集
- **編集可能項目**: 作成時と同様（全項目）
- **権限**: 作成者のみ編集可能
- **更新時処理**: リマインド履歴の再生成

#### 2.4.4 サブスクリプション削除
- **機能**: サブスクリプションの削除
- **削除方式**: 物理削除
- **関連データ**: リマインド履歴も削除

#### 2.4.5 サブスクリプション詳細表示
- **機能**: 個別サブスクリプションの詳細情報表示
- **表示内容**:
  - 基本情報
  - リマインド履歴（日数順の降順）

---

### 2.5 リマインド通知機能

#### 2.5.1 リマインド設定
- **機能**: サブスクリプション終了日のリマインド設定
- **設定項目**:
  - リマインド日数（複数設定可能、例：30日前、7日前、1日前）
  - リマインド時間（HH:mm形式）
  - タイムゾーン
  - カスタムメッセージ
  - 通知有効/無効
- **デフォルト設定**: ユーザー設定から取得

#### 2.5.2 リマインド履歴管理
- **機能**: 送信されたリマインド通知の履歴管理
- **表示項目**:
  - サブスクリプション名
  - 送信日時
  - ステータス（送信待ち、送信済み、送信失敗、キャンセル、テスト送信）
  - メッセージ内容
  - エラーメッセージ（失敗時）
  - 日数前（何日前に送信されたか）
- **フィルタリング**:
  - ステータスによるフィルタ
  - 日付範囲によるフィルタ
  - サブスクリプションによるフィルタ
- **ソート**: 送信日時の降順（デフォルト）

#### 2.5.3 リマインド送信
- **機能**: 設定された日時にリマインド通知を送信
- **送信方式**: LINE Messaging API
- **送信タイミング**: 
  - 設定された日数前の指定時刻
  - バッチ処理（cron）による自動送信
- **送信条件**:
  - サブスクリプションがアクティブ
  - 通知が有効
  - ユーザーが有効なLINEトークンを持っている
  - リマインド履歴のステータスが「送信待ち」
- **メッセージ内容**:
  - サービス名
  - 終了日
  - 残り日数
  - 金額
  - カスタムメッセージ（設定されている場合）

#### 2.5.4 テスト送信
- **機能**: リマインド通知のテスト送信
- **用途**: メッセージ内容の確認
- **動作**: 即座にLINEメッセージを送信

#### 2.5.5 メッセージプレビュー
- **機能**: 送信されるメッセージ内容のプレビュー表示
- **表示内容**: 実際に送信されるメッセージ形式

---

### 2.6 LINE連携機能

#### 2.6.1 LINE認証
- **機能**: LINEアカウントとの連携
- **認証フロー**:
  1. LINE認証URLの取得
  2. LINE認証ページへのリダイレクト
  3. 認証完了後のコールバック処理
  4. アクセストークン・リフレッシュトークンの保存
- **保存情報**:
  - LINEユーザーID
  - アクセストークン（暗号化）
  - リフレッシュトークン（暗号化）
  - トークン有効期限
  - LINE表示名
  - LINEプロフィール画像URL
  - スコープ情報

#### 2.6.2 LINE連携状態確認
- **機能**: 現在のLINE連携状態の確認
- **表示内容**:
  - 連携状態（連携済み/未連携）
  - LINE表示名
  - 連携日時

#### 2.6.3 LINE連携解除
- **機能**: LINEアカウントとの連携解除
- **動作**: トークンの無効化（物理削除は行わない）

---

### 2.7 統計・分析機能

#### 2.7.1 リマインド統計
- **機能**: リマインド通知の統計情報表示
- **表示項目**:
  - 送信済み通知数
  - 送信失敗通知数
  - 送信成功率
  - 月別送信数
  - ステータス別の内訳

#### 2.7.2 月別集計
- **機能**: 月別のリマインド送信数の集計
- **表示形式**: グラフまたはテーブル
- **期間**: 過去12ヶ月（デフォルト）

#### 2.7.3 サブスクリプション分析
- **機能**: サブスクリプションに関する分析情報
- **表示項目**:
  - アクティブなサブスクリプション数
  - 期限切れサブスクリプション数
  - 月額合計金額
  - 契約タイプ別の内訳

---

### 2.8 ユーザー設定機能

#### 2.8.1 デフォルト設定
- **機能**: サブスクリプション作成時のデフォルト値設定
- **設定項目**:
  - デフォルトリマインド日数（配列形式）
  - デフォルトリマインド時間（HH:mm形式）
  - タイムゾーン
  - デフォルトカスタムメッセージ
  - 通知有効/無効
  - LINE通知有効/無効
  - メール通知有効/無効
  - 通貨（JPY, USD, EUR）
  - 日付フォーマット（Y-m-d, Y/m/d, d/m/Y, m/d/Y）
  - テーマ（ライト、ダーク、自動）

#### 2.8.2 設定の適用
- **機能**: 設定したデフォルト値の適用
- **適用タイミング**: 新規サブスクリプション作成時

## 3. 非機能要件

### 3.1 パフォーマンス要件
- **レスポンス時間**: APIレスポンスは2秒以内
- **同時接続数**: 100ユーザーまで対応
- **データベース**: 適切なインデックス設定による高速検索

### 3.2 セキュリティ要件
- **認証**: Laravel Sanctumによるトークンベース認証
- **認可**: ユーザーは自分のデータのみアクセス可能
- **データ保護**: 
  - パスワードのハッシュ化（bcrypt）
  - LINEトークンの暗号化保存
  - SQLインジェクション対策（Eloquent ORM）
  - XSS対策（Reactの自動エスケープ）
- **HTTPS**: 本番環境ではHTTPS必須

### 3.3 可用性要件
- **稼働率**: 99%以上
- **バックアップ**: データベースの定期バックアップ

### 3.4 保守性要件
- **コード品質**: 
  - PSR-12準拠（PHP）
  - ESLint準拠（JavaScript）
  - 日本語コメントの記述
- **ドキュメント**: 
  - コード内コメント（JSDoc/docstring形式）
  - API仕様書

### 3.5 互換性要件
- **ブラウザ**: 
  - Chrome（最新版）
  - Firefox（最新版）
  - Safari（最新版）
  - Edge（最新版）
- **レスポンシブデザイン**: モバイル・タブレット・デスクトップ対応

### 3.6 拡張性要件
- **アーキテクチャ**: 
  - RESTful API設計
  - コンポーネントベース設計（React）
  - サービス層の分離（Laravel）

## 4. データモデル

### 4.1 エンティティ一覧

#### 4.1.1 User（ユーザー）
- **主キー**: id
- **属性**:
  - name: ユーザー名
  - email: メールアドレス（一意）
  - password: パスワード（ハッシュ化）
  - email_verified_at: メール認証日時
- **リレーション**:
  - hasMany: Todo
  - hasMany: Subscription
  - hasMany: ReminderHistory
  - hasMany: LineToken
  - hasOne: UserSetting

#### 4.1.2 Todo（Todoアイテム）
- **主キー**: id
- **属性**:
  - user_id: ユーザーID（外部キー）
  - title: タイトル
  - order: 表示順序
  - deleted_at: 削除日時（ソフトデリート）
- **リレーション**:
  - belongsTo: User
  - hasMany: TodoDetail

#### 4.1.3 TodoDetail（Todo詳細）
- **主キー**: id
- **属性**:
  - todo_id: Todo ID（外部キー）
  - description: 説明
  - completed: 完了状態（boolean）
  - order: 表示順序
  - deleted_at: 削除日時（ソフトデリート）
- **リレーション**:
  - belongsTo: Todo

#### 4.1.4 Subscription（サブスクリプション）
- **主キー**: id
- **属性**:
  - user_id: ユーザーID（外部キー）
  - service_name: サービス名
  - description: 説明
  - start_date: 契約開始日
  - end_date: 契約終了日
  - amount: 金額（decimal 10,2）
  - contract_type: 契約タイプ（enum: monthly, yearly, free_trial, one_time, other）
  - url: URL
  - status: ステータス（enum: active, expired, cancelled, paused, pending_renewal）
  - reminder_days: リマインド日数（JSON配列）
  - reminder_time: リマインド時間（time）
  - timezone: タイムゾーン
  - custom_message: カスタムメッセージ
  - notification_enabled: 通知有効/無効（boolean）
- **リレーション**:
  - belongsTo: User
  - hasMany: ReminderHistory

#### 4.1.5 ReminderHistory（リマインド履歴）
- **主キー**: id
- **属性**:
  - subscription_id: サブスクリプションID（外部キー）
  - user_id: ユーザーID（外部キー）
  - days_before: 日数前
  - scheduled_at: 送信予定日時
  - sent_at: 送信日時
  - status: ステータス（enum: pending, sent, failed, cancelled, test）
  - message: メッセージ内容
  - error_message: エラーメッセージ
  - line_message_id: LINEメッセージID
  - is_read: 既読状態（boolean）
- **リレーション**:
  - belongsTo: Subscription
  - belongsTo: User

#### 4.1.6 LineToken（LINEトークン）
- **主キー**: id
- **属性**:
  - user_id: ユーザーID（外部キー）
  - line_user_id: LINEユーザーID
  - access_token: アクセストークン（暗号化）
  - refresh_token: リフレッシュトークン（暗号化）
  - token_expires_at: トークン有効期限
  - line_display_name: LINE表示名
  - line_picture_url: LINEプロフィール画像URL
  - scope: スコープ（JSON配列）
  - is_active: アクティブ状態（boolean）
  - linked_at: 連携日時
  - last_used_at: 最終利用日時
- **リレーション**:
  - belongsTo: User

#### 4.1.7 UserSetting（ユーザー設定）
- **主キー**: id
- **属性**:
  - user_id: ユーザーID（外部キー、一意）
  - default_reminder_days: デフォルトリマインド日数（JSON配列）
  - default_reminder_time: デフォルトリマインド時間（time）
  - timezone: タイムゾーン
  - default_custom_message: デフォルトカスタムメッセージ
  - notification_enabled: 通知有効/無効（boolean）
  - line_notification_enabled: LINE通知有効/無効（boolean）
  - email_notification_enabled: メール通知有効/無効（boolean）
  - currency: 通貨（enum: JPY, USD, EUR）
  - date_format: 日付フォーマット（enum: Y-m-d, Y/m/d, d/m/Y, m/d/Y）
  - theme: テーマ（enum: light, dark, auto）
- **リレーション**:
  - belongsTo: User

#### 4.1.8 Event（イベント）
- **主キー**: id
- **属性**:
  - user_id: ユーザーID（外部キー）
  - name: イベント名
  - deadline: 期限日
- **リレーション**:
  - belongsTo: User

## 5. API仕様

### 5.1 認証エンドポイント

#### POST /api/register
- **説明**: ユーザー登録
- **リクエスト**:
  ```json
  {
    "name": "ユーザー名",
    "email": "user@example.com",
    "password": "password123"
  }
  ```
- **レスポンス**: 201 Created
  ```json
  {
    "user": { ... },
    "token": "認証トークン"
  }
  ```

#### POST /api/login
- **説明**: ログイン
- **リクエスト**:
  ```json
  {
    "email": "user@example.com",
    "password": "password123"
  }
  ```
- **レスポンス**: 200 OK
  ```json
  {
    "user": { ... },
    "token": "認証トークン"
  }
  ```

#### POST /api/logout
- **説明**: ログアウト
- **認証**: 必須
- **レスポンス**: 200 OK

#### GET /api/me
- **説明**: 現在のユーザー情報取得
- **認証**: 必須
- **レスポンス**: 200 OK
  ```json
  {
    "id": 1,
    "name": "ユーザー名",
    "email": "user@example.com"
  }
  ```

#### PUT /api/profile
- **説明**: プロフィール更新
- **認証**: 必須
- **リクエスト**:
  ```json
  {
    "name": "新しいユーザー名",
    "email": "newemail@example.com"
  }
  ```

### 5.2 Todoエンドポイント

#### GET /api/todos
- **説明**: Todo一覧取得
- **認証**: 必須
- **レスポンス**: 200 OK
  ```json
  [
    {
      "id": 1,
      "title": "Todoタイトル",
      "order": 1,
      "todoDetails": [ ... ]
    }
  ]
  ```

#### POST /api/todos
- **説明**: Todo作成
- **認証**: 必須
- **リクエスト**:
  ```json
  {
  ```

## 7. バッチ処理・スケジューラー

### 7.1 リマインド送信バッチ
- **コマンド**: `php artisan reminders:send`
- **実行頻度**: 1分ごと（cron）
- **処理内容**:
  1. 送信待ち（pending）のリマインド履歴を取得
  2. 送信予定日時が現在時刻と一致するものを抽出
  3. LINE Messaging APIでメッセージ送信
  4. 送信結果をリマインド履歴に記録
- **オプション**:
  - `--type=all`: すべてのリマインドを送信（デフォルト）
  - `--type=events`: イベントリマインドのみ
  - `--type=subscriptions`: サブスクリプションリマインドのみ
