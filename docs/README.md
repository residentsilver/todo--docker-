## 🎓 CI/CDとは？

### CI (Continuous Integration)

- コードをpush → 自動テスト実行
- コード品質を自動チェック
- 問題を早期発見

### CD (Continuous Deployment)

- テスト成功 → 自動デプロイ
- 手動作業を削減
- 一貫性のあるデプロイ

### このプロジェクトでの実装

- **トリガー**: `staging`ブランチへのマージ
- **実行内容**: 依存関係のインストール → ビルド → 自動デプロイ
- **テスト**: 不要（要件により）

- ✅ サーバーにgit連携済み
